# 中国招聘渠道选择

| 渠道 | 主要场景 | 使用要点 |
|---|---|---|
| BOSS直聘 | 通用社招、互联网、服务业 | 公开页面用于发现；完整沟通通常在登录会话内完成 |
| 猎聘 | 中高端岗位、猎头岗位 | 区分企业直招与猎头发布，核对实际雇主 |
| 智联招聘 | 通用社招、传统行业、区域招聘 | 结合城市和更新时间缩小范围 |
| 前程无忧 | 通用社招、制造业、外企 | 同一职位可能跨城市重复发布，合并后保留地点差异 |
| 拉勾 | 互联网和技术岗位 | 优先核对公司官网职位页与技术栈 |
| 脉脉招聘 | 互联网、内推、行业信息 | 将动态讨论与正式职位分开，职位事实以招聘页为准 |
| 国聘 | 央国企、校招 | 核对招聘批次、报名截止时间和附件要求 |
| 牛客 | 技术校招、实习 | 区分经验帖、题库与正式招聘信息 |
| 高校就业网 | 校招、实习、宣讲会 | 检查毕业年份、学校范围和宣讲时间 |
| 企业官网 | 所有类型 | 作为职位状态、地点和申请入口的优先事实来源 |

## 页面受限时

依次采用：公开搜索结果 → 企业官网 → 搜索引擎 `site:` 查询 → 用户已打开的登录页面 → 用户粘贴的 JD。
记录信息日期和来源；摘要缺字段时保留 unknown，后续进入申请流程前再核验。
